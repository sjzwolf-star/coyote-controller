## 命令格式

### B0 命令 — 波形 + 强度推送

- 长度: 20 字节
- 发送频率: 每 100ms 一次
- 写入方式: Write Without Response

```
Byte 0:     0xB0 (命令头)
Byte 1:     [序列号:4bit | 强度解释:4bit]
Byte 2:     A 通道强度设定值 (0~200)
Byte 3:     B 通道强度设定值 (0~200)
Byte 4-7:   A 通道波形频率 × 4 (每个 10~240)
Byte 8-11:  A 通道波形强度 × 4 (每个 0~100)
Byte 12-15: B 通道波形频率 × 4
Byte 16-19: B 通道波形强度 × 4
```

**强度解释码** (Byte 1 低 4 位):

| 码值 | 含义 |
|------|------|
| `0000` | 不改变强度 |
| `0100` | A 通道相对增加 |
| `1000` | A 通道相对减少 |
| `1100` | A 通道绝对设定 |
| `0001` | B 通道相对增加 |
| `0010` | B 通道相对减少 |
| `0011` | B 通道绝对设定 |

高 2 位控制 A 通道，低 2 位控制 B 通道，可组合使用。

**序列号**: Byte 1 高 4 位，范围 0x1~0xF。每次发送强度变化时递增，0 表示不跟踪。设备在 B1 通知中回显相同序列号，表示已处理该指令。

### BF 命令 — 软上限 + 平衡参数

- 长度: 7 字节
- 写入方式: Write Without Response

```
Byte 0: 0xBF
Byte 1: A 上限 (0~200)
Byte 2: B 软上限 (0~200)
Byte 3: A 频率平衡参数 (0~255)
Byte 4: B 频率平衡参数 (0~255)
Byte 5: A 强度平衡参数 (0~255)
Byte 6: B 强度平衡参数 (0~255)
```

软上限限制通道最大强度，设备关机后仍然保存。BF 命令立即生效且无返回值。

### B1 通知 — 强度回显

- 长度: 4 字节
- 通过 0x150B Characteristic 通知

```
Byte 0: 0xB1
Byte 1: 序列号 (与 B0 的 seq 匹配, 0 表示物理滚轮变化)
Byte 2: A 通道当前实际强度
Byte 3: B 通道当前实际强度
```

当序列号 > 0 且与 pendingSeq 匹配时，表示设备已处理指令，可以发送下一条强度变化。

当序列号 = 0 时，表示用户通过物理滚轮改变了强度，应用应更新 UI 显示。

## 频率压缩算法

用户友好值 (10~1000) 压缩为蓝牙传输字节 (10~240):

| 输入范围 | 计算公式 | 输出范围 |
|----------|----------|----------|
| 10~100 | 原值 | 10~100 |
| 101~600 | (值 - 100) / 5 + 100 | 101~200 |
| 601~1000 | (值 - 600) / 10 + 200 | 201~240 |

## 通道禁用

要禁用某个通道的输出，在该通道的强度字节中发送 `101`（超出 0~100 范围），设备会丢弃该通道的波形数据。

## 内置波形定义

### 呼吸 (Breathing)
12 个切片，强度从 0 渐变到 100 再回到 0。

### 潮汐 (Tide)
24 个切片，频率和强度同时渐变，模拟潮水起伏。

### 持续 (Steady)
4 个切片，恒定 50% 强度持续输出。

### 脉冲 (Pulse)
4 个切片，100% 和 0% 交替，产生脉冲效果。

## 安全注意事项

1. 每次连接后应先设置较低的软上限（如 50/50）
2. BF 命令立即生效且无返回值，重连后必须重新设置
3. 停止发送 B0 后设备会自动停止输出（约 300ms 超时）
4. 强度范围 0~200，超出范围的值会被视为 0
5. 波形频率范围 10~240，超出范围会导致该通道数据被丢弃
6. B0 必须每 100ms 持续发送，中断会导致设备自动停止输出
